# zBreakOut

Juego 2D estilo Breakout / Arkanoid creado con Unity.

## Controles

- `A`, `D` o flechas: mover la pala.
- Movimiento del mouse: mover la pala.
- `Espacio`, `Enter` o clic: lanzar la pelota.
- `R`: reiniciar la partida.
- `Esc`: salir del juego.

## Build

El ejecutable para Windows se genera en la carpeta `build`.
