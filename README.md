# zBreakOut

Juego 2D estilo Breakout / Arkanoid creado con Unity.

## Abrir correctamente

- Para inspeccionar el proyecto visualmente, ejecutar `ABRIR_EN_UNITY.bat`.
- En Unity, abrir `Assets/Scenes/Main.unity` y usar el boton Play de la barra superior.
- La jerarquia `VISUAL PREVIEW - Breakout Level` contiene la camara, el fondo, las paredes, la pala, la pelota y los 60 ladrillos visibles desde el editor.
- No ejecutar `Assets/Scripts/BreakoutGame.cs` desde Visual Studio Code: es un componente de Unity, no un programa independiente.

## Controles

- `A`, `D` o flechas: mover la pala.
- Movimiento del mouse: mover la pala.
- `Espacio`, `Enter` o clic: lanzar la pelota.
- `R`: reiniciar la partida.
- `Esc`: salir del juego.

## Build

El ejecutable para Windows esta en `build/zBreakOut.exe`. Tambien puede iniciarse con `JUGAR_zBreakOut.bat`.
